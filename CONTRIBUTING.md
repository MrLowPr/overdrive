# Panduan Kontribusi

Terima kasih sudah ingin berkontribusi ke **overdrive**.

## Alur Kerja

1. Fork repo ini dan buat branch: `git checkout -b feat/nama-fitur`
2. Lakukan perubahan dan pastikan CI lulus
3. Commit dengan format [Conventional Commits](https://www.conventionalcommits.org/):
   `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`
4. Push dan buka Pull Request ke branch `main`

## Standar

- Satu PR untuk satu tujuan
- Sertakan pengujian bila menambah/mengubah perilaku
- Perbarui dokumentasi yang terdampak
